# English with Tanya v8

Главные изменения:
- яркие цветные иллюстрации вместо серых карточек;
- отдельный раздел «Не знаю»;
- счётчик нажатий «Не знаю» для каждого слова;
- неправильные ответы и «Не знаю» больше не смешиваются;
- сохраняется текущий день, номер задания, результат и ответы;
- после закрытия можно продолжить урок с того же места;
- незавершённый урок показывается на главной.
